# 🚀 Socrademy - Roadmap развития проекта

## 📋 Обзор проекта
**Socrademy** - платформа для эффективного обучения по методу Сократа с использованием ИИ, с минимумом теории и созданием структурированных обучающих курсов.

### 🎯 Ключевые особенности
- Обучение по методу Сократа через ИИ
- Создание структуры обучающих курсов
- Отслеживание прогресса ученика
- Комментирование и анализ обучения
