# 🚀 LearnUs Landing Page

Продающий лендинг для платформы LearnUs (Socrademy) - революционной платформы обучения с ИИ по методу Сократа.

## 📋 Особенности лендинга

### ✨ Дизайн и UX
- **Минималистичный современный дизайн** с фокусом на конверсию
- **Красивые анимации и переходы** для привлечения внимания
- **Полная мобильная адаптивность** (mobile-first подход)
- **Быстрая загрузка** (<3 секунд)
- **SEO-оптимизация** для поисковых систем

### 🎯 Психологические триггеры
- **FOMO** (ограниченное предложение)
- **Социальное доказательство** (статистика, отзывы)
- **Авторитет** (научный подход)
- **Контраст** (старое vs новое обучение)
- **Конкретность** (цифры и результаты)

### 📱 Технические характеристики
- **HTML5 + CSS3 + JavaScript** (без тяжелых библиотек)
- **Адаптивный дизайн** для всех устройств
- **Анимации на CSS/JS** для плавности
- **Интеграция с аналитикой** (Google Analytics, Facebook Pixel)
- **Структурированные данные** для SEO

## 🎨 Цветовая схема

- **Основной**: `#2563EB` (синий - доверие, технологии)
- **Акцент**: `#10B981` (зеленый - рост, успех)
- **Текст**: `#1F2937` (темно-серый)
- **Фон**: `#FFFFFF` (белый)

## 📁 Структура файлов

```
landing.html          # Основной HTML файл
landing.css           # Стили и анимации
landing.js            # Интерактивность

```

## 🚀 Запуск лендинга

1. **Локальный запуск:**
   ```bash
   # Откройте landing.html в браузере
   open landing.html
   ```

2. **Серверный запуск:**
   ```bash
   # Используйте любой локальный сервер
   python -m http.server 8000
   # или
   npx serve .
   ```

## 🎯 Оптимизация конверсии

### A/B тестирование элементов:
- **Заголовки** - тестируйте разные варианты
- **CTA кнопки** - цвет, текст, размер
- **Цены** - отображение, скидки, гарантии
- **Отзывы** - количество, формат, авторы

### Метрики для отслеживания:
- **Конверсия в регистрацию** (цель: 3-5%)
- **Время на странице** (цель: >2 минут)
- **Прокрутка до CTA** (цель: >60%)
- **Клик по CTA** (цель: >15%)

```javascript
fbq('init', 'YOUR_PIXEL_ID');
```

- `conversion` - клик по CTA
- `scroll` - прокрутка до секций
- `time_on_page` - время на странице
- `form_submit` - отправка форм
